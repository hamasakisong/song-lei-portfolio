页面层 JSP

运营后台、商户收银台、登录页。

控制层 MVC

Controller 处理请求、参数和页面跳转。

业务服务

活动、发券、券管理、核销、统计。

数据层

JdbcTemplate + MySQL 表。

业务闭环

发券进入生命周期，核销写流水。

本期范围

运营后台创建活动、按手机号发券、券查询作废、商户核销、运营统计。

暂不接入

H5 领券、短信平台、支付系统、清结算系统、退货返券、核销撤销。
