# 右上角玻璃胶囊导航设计

## 目标

保留现有右上角纯导航、无 Logo 的结构，提升玻璃胶囊质感，并增加克制的液态活动底座动效。导航应强化当前页面与悬停目标，但不能抢占首页标题、背景插画和项目卡片的注意力。

## 视觉规格

- 外层导航保持半透明白色玻璃胶囊、柔和边框与轻微背景模糊。
- 菜单项内部增加一个低饱和青绿色的圆角活动底座，透明度低于主按钮背景。
- 悬停某项时，活动底座平滑滑到该项；文字颜色加深，不增加发光、弹跳或双层文字翻转。
- 鼠标移出导航后，活动底座回到当前页面对应项。
- 当前项文字保持深墨绿色，其他项目保持柔和灰绿色。

## 当前项规则

- `/`：首页。
- `/#work`、`/projects/:slug`：精选案例。
- `/experience`：经验沉淀。
- `/about`：关于我。

## 交互与无障碍

- 鼠标悬停、键盘焦点与点击都通过同一导航项模型更新活动底座。
- 键盘焦点可见，且不依赖颜色作为唯一提示。
- `prefers-reduced-motion: reduce` 下，活动底座直接定位，不播放滑动动画。
- 移动端保留现有菜单按钮与展开面板；桌面活动底座不进入窄屏菜单。

## 技术方案

不引入 GSAP。将桌面导航数据集中为一组项目，并在 `SiteShell` 内维护短暂的悬停目标。使用 `useLocation` 计算稳定的当前项，活动底座以 CSS 自定义属性表示横向位置与宽度；CSS `transform` 与 `width` 负责过渡。这样不额外增加依赖，也避免单独为每个链接编写动画状态。

## 验收标准

- [ ] 桌面端导航仍位于右上角，只有首页、精选案例、经验沉淀、关于我四项。
- [ ] 悬停任一项时，低饱和活动底座平滑移动到该项。
- [ ] 鼠标离开后，活动底座回到当前页面项。
- [ ] 从项目详情页进入时，“精选案例”是当前项。
- [ ] 点击任一入口后，URL、页面内容与当前项一致。
- [ ] Tab 聚焦时有清晰焦点和相同底座反馈。
- [ ] 开启减少动态效果时，底座不进行过渡。
- [ ] 移动端菜单仍可正常展开、关闭和跳转。

## 非目标

- 不加入 Logo、头像、音乐、深色主题或 GSAP。
- 不修改导航入口数量、页面路由、首页背景或项目卡片动效。
- 不改变移动端菜单的信息架构。
