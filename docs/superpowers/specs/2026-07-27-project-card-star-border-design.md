# 项目卡片 StarBorder 悬停边框设计

## 目标

用持续循环的银白色上下扫光替换项目卡片现有的单点流星边框。效果仅在悬停或键盘焦点期间出现，并保持在卡片边缘，不进入正文区域。

## 视觉规格

- 默认状态保留当前低对比细边框，不显示扫光。
- 悬停时，在卡片顶部和底部各出现一个大范围径向渐变光团。
- 两个光团沿相反方向持续移动，形成连续、柔和的星光扫边。
- 核心颜色为亮银白，外沿为浅冷灰并渐隐至透明；不使用青绿、霓虹或彩色光。
- 单轮速度为 4.8 秒，`linear infinite alternate`，鼠标移开后立即停止并淡出。
- 光效透明度控制在约 0.62，必须可见但不能压过标题与摘要。

## 交互与无障碍

- 触发条件：`.project-card__link:hover` 和 `.project-card__link:focus-visible`。
- 光效元素为装饰层：`aria-hidden="true"`、`pointer-events: none`。
- 卡片的点击、上浮、阴影和箭头反馈保持不变。
- `prefers-reduced-motion: reduce` 下不播放扫光，维持静态边框。

## 技术方案

移除当前 `.project-card__meteor` SVG 路径与其 keyframes。保留一个装饰性包装层，内部使用两个 span：顶部与底部光团。它们分别使用 `radial-gradient(circle, rgba(255,255,255,.95), transparent 10%)`，尺寸为卡片宽度的 300%，在裁切容器内水平反向移动。

不引入 React Bits 组件文件、GSAP 或新依赖；只吸收 StarBorder 的 CSS 技法，并适配现有项目卡片结构、明亮背景和 B 端作品集气质。

## 验收标准

- [ ] 悬停任意项目卡片，顶部和底部出现持续循环的银白扫光。
- [ ] 光效只在卡片边缘可见，不出现正文内部竖线或整圈高亮。
- [ ] 鼠标移出后扫光停止，卡片回到默认细边框。
- [ ] 卡片仍能正常点击，上浮和箭头反馈不受影响。
- [ ] Tab 聚焦可触发同样效果。
- [ ] 减少动态效果开启时不播放。
- [ ] 移动端不产生横向溢出或内容遮挡。

## 非目标

- 不改变项目卡片内容、排序、尺寸、背景或跳转路径。
- 不修改案例详情页的卡片或其他页面动效。
- 不增加 Logo、GSAP、Canvas、视频或持续全页面动效。
