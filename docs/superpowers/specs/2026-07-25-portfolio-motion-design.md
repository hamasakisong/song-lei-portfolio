# 个人作品集动效升级设计

## 目标

在不改变现有内容、视觉基调和隐私策略的前提下，为首页和项目详情页增加克制的滚动叙事与卡片交互。效果应传达“规划清晰、交付可靠”，而不是追求炫技。

## 范围

- 覆盖：首页、项目详情页。
- 不覆盖：关于我、经验专题页的新增动效改造。
- 保持：手机号、邮箱、简历下载入口继续隐藏；现有路由和项目内容不变。

## 设计方向

采用“克制的叙事型动效”。借鉴参考视频的分层进入、错速滚动、卡片交互和深浅区块节奏，但不引入大幅缩放、自动轮播、持续闪烁或背景音乐。

## 首页

### 首屏

- 现有标题、简介、行动按钮和数据证明维持分层进入。
- 雾感背景保留，并仅随鼠标或滚动产生轻微视差。
- 动效总时长控制在首屏可读性优先的范围内，避免用户等待。

### 精选案例

- 项目卡片随滚动按顺序出现，保留短间隔的错位节奏。
- 悬停时卡片上移、边框与阴影轻微增强，右下角箭头向前移动。
- 卡片角落光晕从弱到强扩散；离开时平滑恢复。
- 不使用持续循环的卡片动画。

### 工作方法

- 四个步骤按阅读顺序显现，强调“理解现场 → 建立模型 → 规划取舍 → 推动落地”。
- 每一步只使用轻微透明度和位移变化，不创建额外的复杂交互。

## 项目详情页

### 桌面端构图

- 采用编辑式双栏：左侧窄项目卡片，右侧宽要点叙事。
- 左卡展示编号、项目名称、简述和标签，作为案例封面。
- 右侧依次展示业务背景、核心判断、方案设计和交付价值；每个部分维持一行一行、易扫描的阅读结构。
- 在详情页主要阅读区间内，左卡保持在视野中；滚动到内容尾部后自然释放，不能遮挡页脚或后续内容。

### 入场与交互

- 页面进入时：左卡先落位；一条细光束沿边框绕行一圈后停止。
- 光束仅播放一次，不循环，不在悬停时重新播放。
- 右侧内容以约 70ms 的间隔逐项显现。
- 滚动中，左卡与右侧内容只发生轻微位移和透明度变化。

## 响应式与无障碍

- 移动端切换为单栏：项目卡在内容前方，取消粘性停留。
- 小屏幕保留一次性入场提示，但减少延迟和复杂位移。
- 检测到“减少动态效果”偏好时：关闭光束、视差和悬停位移；内容直接可见。
- 不改变语义标签、键盘可访问性或现有链接行为。

## 技术边界

- 复用现有 Motion/React 动画体系和现有 CSS 设计变量。
- 不新增第三方动效库，不增加视频或大尺寸图片资源。
- 动效必须避免造成页面布局抖动，且不能阻塞项目详情页的直接访问。

## 验收标准

1. 首页首屏、案例卡片和工作方法区体现清晰的分层叙事。
2. 案例卡片悬停效果平滑，离开后可恢复初始状态。
3. 项目详情页在桌面端呈现左卡右要点构图。
4. 详情页左卡的光束仅在页面进入时绕行一次。
5. 首页、详情页在移动端无横向溢出，阅读顺序正确。
6. 开启系统“减少动态效果”后，信息仍能直接阅读且无持续动画。
7. 现有测试、构建和国内/海外静态部署路由保持可用。
