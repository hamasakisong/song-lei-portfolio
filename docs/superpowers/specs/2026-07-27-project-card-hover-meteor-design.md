# 项目卡片悬停流星边框设计

## 目标

当鼠标进入精选案例卡片时，出现一个亮银色、带渐隐拖尾的流星亮点。亮点从卡片右上角出发，顺时针沿边框完整移动一圈后消失。它只作为悬停反馈，不改变卡片的点击行为、内容层级或既有上浮效果。

## 范围

- 目标元素：`src/components/project/ProjectCard.tsx` 渲染的每一张精选案例卡片。
- 触发条件：鼠标悬停卡片链接，或键盘焦点进入卡片链接。
- 动画次数：每次进入仅播放一圈；鼠标离开后再次进入可重新播放。
- 轨迹：从右上角开始，沿上边向左、左边向下、下边向右、右边向上完成顺时针闭环。
- 时长：约 1.8 秒；动画结束后不保留发光边框。

## 视觉规格

- 核心亮点为银白色，使用白色中心和浅灰银色外晕，不使用荧光绿或青色。
- 拖尾位于亮点后方，长度约为整圈的 12% 至 16%，由亮到暗自然衰减。
- 常态边框保持当前的低对比细线；动画仅临时覆盖在其上方。
- 流星层 `pointer-events: none`，不会遮挡文字、链接、鼠标或键盘交互。

## 技术方案

在项目卡片链接内增加一个仅用于装饰的 SVG 覆盖层：

- 使用从右上角直接起笔、沿右边向下的闭合路径，确保任意卡片宽高比下都顺时针贴边；
- 用两条描边叠加形成银白色核心与短拖尾；
- 覆盖层默认不可见；在 `.project-card__link:hover` 与 `.project-card__link:focus-visible` 下推进一整圈；
- `@media (prefers-reduced-motion: reduce)` 中不播放该覆盖层。

路径按卡片本身的宽高拉伸，亮点只会沿四条边移动，不会进入卡片正文。

## 验收标准

- [ ] 悬停任一项目卡片，流星从右上角开始顺时针跑完一圈并停止。
- [ ] 鼠标持续停留时，动画不自动循环。
- [ ] 鼠标移出并重新进入时，动画重新从右上角开始播放。
- [ ] 卡片仍可点击进入案例；上浮、阴影和箭头交互保持可用。
- [ ] 键盘 Tab 聚焦卡片时也会得到同等的动效提示。
- [ ] 用户启用“减少动态效果”时，动画不会播放。
- [ ] 移动端不因该装饰产生横向溢出或遮挡。

## 非目标

- 不修改项目卡片的内容、尺寸、排序或背景。
- 不修改案例详情页已有的单次流星边框。
- 不增加外部依赖、Canvas、视频或持续性背景动效。
